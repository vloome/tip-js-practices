## Организация кода

В решении задачи реализовано строгое разделение ответственности между модулями:

* **`src/data.js`** — содержит общие демонстрационные данные (`demoTasks`), номер варианта (`variantNumber`) и индивидуальный набор задач для варианта 4 (`variantTasks`). Не содержит логики и работы с DOM.
* **`src/task-service.js`** — прикладной модуль, перенесённый из ПР2, содержащий чистые функции для создания, чтения, изменения и удаления задач (проходят валидацию, используют иммутабельность, не содержат побочных эффектов вроде `console.log` и обращений к DOM).
* **`src/task-selectors.js`** — отвечает за отбор задач. Содержит функцию `getVisibleTasks(tasks, filter)`, которая формирует новую выборку в зависимости от выбранного режима (`all`, `pending`, `completed`) без мутации исходных данных.
* **`src/task-view.js`** — модуль визуализации и работы с DOM. Отвечает за создание карточек (`createTaskElement`), обновление списка (`renderTaskList`), расчет и вывод общей сводки (`renderSummary`), а также управление отображением пустых состояний (`renderEmptyState`).
* **`src/main.js`** — главный координирующий модуль. Хранит полное текущее состояние приложения (`currentTasks` и `currentFilter`), обрабатывает пользовательские события посредством делегирования (`handleTaskListClick`, `handleFilterClick`), вызывает функции прикладного сервиса и координирует обновление интерфейса через `renderApp`.

## Отладка и клавиатура

### Точка останова и исследование события (DevTools)
* **Точка останова:** `src/main.js`, строка в обработчике `taskListContainer.addEventListener('click', ...)` (проверка события клика по карточке).
* **Полученные значения при клике на кнопку выполненности задачи #4:**
  * `event.target`: `<span class="action-label">Выполнена</span>` (вложенный элемент подписи кнопки)
  * `event.currentTarget`: `<ul id="task-list" class="task-list">...</ul>` (контейнер, на котором висит делегированный обработчик)
  * `dataset.taskId`: `"4"` (получено из ближайшей родительской карточки через `.closest('.task-card')`)
  * Числовой `id`: `4` (после преобразования `Number("4")`)
  * `action`: `"toggle"` (значение атрибута `data-action` кнопки)
  * **Результат работы сервиса:** `{ ok: true, tasks: [...] }` (успешное изменение статуса задачи)

### Клавиатурная навигация и доступность

* **Клавиша `Tab`:** последовательно перемещает фокус по всем интерактивным элементам страницы — ссылкам в шапке, кнопкам фильтрации («Все», «В работе», «Выполненные») и интерактивным кнопкам действий в карточках задач («Выполнить» / «Выполнена», «Удалить»).
* **Клавиши `Enter` и `Space`:** корректно активируют выбранный фильтр или выполняют действие над задачей при нахождении фокуса на соответствующей кнопке.
* **Сохранение фокуса:** после перерисовки DOM при смене статуса или фильтрации фокус с помощью `.focus()` программно восстанавливается на активной кнопке, что предотвращает его сброс на `document.body` и обеспечивает комфортную навигацию с клавиатуры.
* **Защита от некорректных атрибутов:** при изменении `data-task-id` в DevTools на нечисловые или несуществующие значения (`777`, `4abc`) приложение корректно обрабатывает ошибку: данные в состоянии приложения не мутируют, а в элементе `#operation-message` выводится понятное текстовое предупреждение.
