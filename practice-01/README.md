## 7. Задание 5. Поиск логических ошибок через DevTools
* **Исходное наблюдение:** Сложение строк `"3" + "2"` привело к конкатенации (`"32"` вместо `5`), а цикл завершался раньше времени из-за строгого неравенства `< 4`.
* **Причина:** Отсутствие явного преобразования типов при чтении текстовых переменных и неверная граница итераций цикла.
* **Исправление:** Добавлено преобразование через `Number()` и скорректировано условие цикла.
* **Иллюстрация:** Скриншот остановки в отладчике сохранён в файле `screenshots/debug-breakpoint.png`.
